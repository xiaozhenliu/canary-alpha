# Security Policy

## Supported Versions

Security fixes are applied to the current `2.x` release line.

| Version | Supported |
|---------|-----------|
| `2.x` | Yes |
| `< 2.0` | No |

## Reporting a Vulnerability

Do not report suspected vulnerabilities through public GitHub issues,
discussions, or pull requests.

Use the repository's private
[GitHub Security Advisory form](https://github.com/xiaozhenliu/canary-alpha/security/advisories/new)
to report a vulnerability. Include:

- the affected version or commit;
- the impact and affected component;
- reproduction steps or a proof of concept;
- any suggested mitigation, if available.

External reporters can use this form when GitHub Private vulnerability
reporting is enabled for the repository. If the private form is unavailable,
do not disclose the issue publicly. Repository maintainers should enable
Private vulnerability reporting before accepting external security reports.

Reports will be reviewed privately. Maintainers will coordinate remediation,
release timing, and disclosure based on the issue's impact.

For general bugs and feature requests, use the public issue forms instead.
