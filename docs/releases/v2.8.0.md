# computer-history-mcp v2.8.0

[English](v2.8.0.md) | [简体中文](../zh/releases/v2.8.0.md)

`computer-history-mcp` is a local-first MCP server that turns Screenpipe activity into searchable computer history and persistent memory for AI agents. It runs on your Mac, keeps captured and derived data local by default, and exposes a loopback-only Streamable HTTP endpoint for Codex, Claude, Cursor, Hermes, and other MCP-compatible clients.

This is the first complete public release.

## What it provides

- **Searchable work history:** keyword, semantic, and hybrid search across captured screen activity.
- **Recall and inspection:** reconstruct bounded work sessions, summaries, supporting frames, and evidence.
- **Persistent agent memory:** separate local memory and user scopes that survive individual conversations.
- **Structured activity extraction:** Universal AXTree extraction, enriched session labels, and session-scoped delta deduplication.
- **Privacy controls:** pause or resume capture, exclude applications, delete time ranges, and use safer recorder defaults.
- **Local operations:** an embedded Dashboard for health, configuration, routines, activity, privacy, and logs.
- **Scheduled routines:** cron-based prompts that retrieve relevant local evidence and optionally call a configured LLM.
- **Portable MCP access:** the same 12-tool surface over managed Streamable HTTP or local stdio.

## How it relates to Computer Use

Computer Use tools operate the current interface by seeing, clicking, typing, and scrolling. `computer-history-mcp` provides the complementary history layer: it records and indexes work context over time so agents can search and recall it later. It is a local open-source alternative for computer history and persistent agent memory, not a replacement for live UI control.

## Requirements

- macOS
- Node.js 22+
- The tested MIT-licensed `screenpipe@0.3.282` release with Screen Recording and Accessibility permissions

Do not substitute `screenpipe@latest`; current upstream releases use a different license and have not been validated with this project.

## Quick start

```bash
npm install --global screenpipe@0.3.282
git clone https://github.com/xiaozhenliu/computer-history-mcp.git
cd computer-history-mcp
npm install
npm start
```

Connect an MCP client to `http://127.0.0.1:18765/mcp`. The onboarding flow configures Hermes automatically.
