# computer-history-mcp v2.8.0

[English](../../releases/v2.8.0.md) | [简体中文](v2.8.0.md)

`computer-history-mcp` 是一个本地优先的 MCP server，将 Screenpipe 活动转化为可搜索的电脑历史和持久 AI agent 记忆。它在 Mac 本机运行，采集数据和派生数据默认保留在本地，并通过仅监听回环地址的 Streamable HTTP endpoint 服务 Codex、Claude、Cursor、Hermes 及其他兼容 MCP 的客户端。

这是本项目第一次完整的公开发布。

## 提供的能力

- **工作历史检索：** 对已采集的屏幕活动进行关键词、语义和混合检索。
- **回顾与检查：** 重建指定时间范围内的工作会话、摘要、支撑帧和证据。
- **持久 agent 记忆：** 独立的本地 memory 和 user scope，不受单次对话生命周期限制。
- **结构化活动提取：** Universal AXTree 提取、session label 增强和 session scope 差量去重。
- **隐私控制：** 暂停或恢复采集、排除应用、删除时间范围，并使用更安全的 recorder 默认值。
- **本地运维：** 内置 Dashboard 提供健康状态、配置、routines、活动、隐私和日志管理。
- **定时 routines：** 使用 cron 调度 prompt，检索相关本地证据，并按需调用已配置的 LLM。
- **通用 MCP 接入：** 通过托管 Streamable HTTP 或本地 stdio 提供相同的 12 个工具。

## 与 Computer Use 的关系

Computer Use 工具通过观察、点击、输入和滚动来操作当前界面。`computer-history-mcp` 提供互补的历史层：长期记录并索引工作上下文，供 agent 日后搜索和回顾。需要电脑历史与持久 agent 记忆时，它是本地开源的替代方案，但不替代实时 UI 控制。

## 环境要求

- macOS
- Node.js 22+
- 经过实测、使用 MIT 许可的 `screenpipe@0.3.282`，并授予屏幕录制和辅助功能权限

不要改用 `screenpipe@latest`；当前上游版本采用不同许可证，且尚未通过本项目验证。

## 快速开始

```bash
npm install --global screenpipe@0.3.282
git clone https://github.com/xiaozhenliu/computer-history-mcp.git
cd computer-history-mcp
npm install
npm start
```

将 MCP 客户端连接到 `http://127.0.0.1:18765/mcp`。初始化流程会自动配置 Hermes。
